# 微商系统 - 面向对象课程设计

基于 **C/S 架构**的社交零售模拟系统，实现商品浏览、购物车、混合促销策略（策略+装饰+工厂）、结算（事务+防超卖）、订单查询、售后退货等功能。

## 技术栈

- **语言/标准**：C++17（MinGW-W64 8.1.0 实测通过）
- **服务端**：Winsock2 + 多线程（Acceptor + 每客户端收发线程 + WorkerPool 线程池）+ SQLite（嵌入式，自动建表初始化）
- **客户端**：控制台交互（UTF-8），策略模式双 UI 风格（极简/详细）
- **通信**：自定义 TCP 应用层协议（16 字节定长头 + JSON 变长体，长度前缀法防粘包）
- **设计模式**：策略（促销/UI）、装饰（促销叠加）、工厂（Handler/促销）、命令（Handler）、观察者（消息队列/订单事件）、单例（TaskQueue）、MVC（客户端）/ 三层架构（服务端）
- **并发**：生产者-消费者消息队列、互斥锁 + SQL 原子扣减双保险防超卖、事务（BEGIN IMMEDIATE）

## 快速开始

### 1. 编译（需要 MinGW-W64 8.1+，含 gcc/g++）

```bat
build.bat
```

### 2. 启动服务端

```bat
build\server.exe
```

首次启动自动创建 `ms.db` 并初始化种子数据（3 用户 / 6 商品 / 4 促销）。按 `q` 回车停止。

### 3. 启动客户端（另开终端）

```bat
build\client.exe
```

### 4. 集成测试（需先启动服务端）

```bat
build\test_client.exe   # 需先单独编译：见 build.bat 注释或 test/README
```

## 设计亮点

- **混合促销**：策略模式定义打折/直降/满减算法族，装饰器层层叠加（如"满200减30 → 9折"），工厂从数据库配置动态创建，新增促销零改动结算核心（开闭原则）
- **防超卖**：`std::mutex` 内存锁 + `UPDATE ... SET stock=stock-? WHERE stock>=?` 数据库原子扣减 + 事务回滚三重保障；8 线程抢 1 件限量库存仅 1 单成功（集成测试验证）
- **观察者模式**：TaskQueue 作为被观察目标，Worker 线程阻塞等待唤醒；订单创建后 OrderEventBus 广播通知监听者
- **粘包处理**：长度前缀法，先读满 16 字节头再按 Length 循环 `recv`
