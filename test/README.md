`test_client.cpp` 是自动化集成测试程序，通过真实 TCP 连接模拟完整业务链路，共 79 项断言。

## 编译

```bat
g++ -std=c++17 -O1 -Ivendor -I. test\test_client.cpp common\ProtocolEncoder.cpp -o build\test_client.exe -lws2_32
```

## 运行（需先启动 build\server.exe）

```bat
build\test_client.exe
```
